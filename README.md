#  Word Count Tool (GUI)

##  Overview

The **Word Count Tool** is a Python-based application with a graphical user interface (GUI) that analyzes text files and provides detailed insights. It calculates the number of words, lines, and characters, and performs word frequency analysis to identify the most commonly used words.

---

## Features

*  Upload and analyze text files
*  Count total words, lines, and characters
*  Word frequency analysis (Top words)
*  Data visualization using bar charts
*  User-friendly GUI built with Tkinter
*  Option to save results

---

##  Technologies Used

* **Python** – Core programming
* **Tkinter** – GUI development
* **Matplotlib** – Data visualization
* **Collections (Counter)** – Frequency analysis

##  Setup Instructions

1. Clone the repository:

```
git clone https://github.com/your-username/word-count-tool.git
```

2. Navigate to the project folder:

```
cd word-count-tool
```

3. Install dependencies:

```
python -m pip install matplotlib
```

4. Run the application:

```
python gui.py
```

---

##  How It Works

1. Launch the application
2. Click on **Upload File**
3. Select a `.txt` file
4. View analysis results and word frequency graph
